# Web Research

A skill for conducting structured web research, searching online resources, and synthesizing factual findings.

## Capabilities

- Search web information, documentation, and articles
- Fetch and summarize online pages and guides
- Cross-verify factual claims and references

## Usage Guidelines

When this skill is active:
1. Provide accurate, up-to-date, and well-structured answers.
2. Clearly cite sources or summarize key points when conducting research.
3. If information is uncertain or time-sensitive, indicate the context clearly.
